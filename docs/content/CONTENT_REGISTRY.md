## 1. NGUYÊN TẮC PHÂN LOẠI NỘI DUNG (4-TIER TAXONOMY)

Toàn bộ nội dung hiển thị trên website Gia Tộc Trần Trọng Thu được phân định nghiêm ngặt thành 4 nhóm theo tính chất quản trị:

| Nhóm | Tên Danh Mục | Định Nghĩa | Chu Kỳ Thay Đổi | Nguồn Dữ Liệu Gốc |
| :--- | :--- | :--- | :--- | :--- |
| **A** | **Editorial Content** | Nội dung biên tập: bài viết văn hóa, chuyên san MẠCH, câu chuyện ký ức, lời hiệu triệu trang chủ, nội dung trợ giúp FAQs, thông báo vận hành máy chủ. | Thường xuyên / Định kỳ theo ấn phẩm | Markdown (`content/`), JSON (`server/data/`), Code templates |
| **B** | **UI Copy** | Nhãn giao diện người dùng: tên nút bấm, tiêu đề biểu mẫu, placeholder, thông báo lỗi, thông báo trạng thái rỗng, badge phân loại. | Hiếm khi thay đổi (chỉ khi tối ưu UX) | Mã nguồn UI components (`src/js/ui/`) |
| **C** | **Configuration** | Cấu hình luồng và điều hướng: danh sách menu (Header/Footer), cây phân cấp URL routes, metadata quyền truy cập, Asset Manifest. | Thay đổi khi tái cấu trúc sitemap / ra mắt tính năng mới | `src/js/ui/navigation.js`, `src/js/ui/shell.js`, `assets/ASSET_MANIFEST.json`, `config/navigation.json` |
| **D** | **Domain Data** | Dữ liệu gia phả hạt nhân: hồ sơ nhân vật, quan hệ huyết thống gia đình, tư liệu di ảnh, niên biểu lịch sử, ngày kỵ giỗ. | Thay đổi có kiểm soát qua hội đồng gia tộc / đề xuất | MariaDB / SQLite (`family_archive.db`), `server/data/*.json`, ICS feeds |
