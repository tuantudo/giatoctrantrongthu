# 04 CANONICALITY EVIDENCE

## OBSERVATION
The system currently holds multiple copies of data. No decisions are made here.

## EVIDENCE METRICS TO GATHER
- **Location Context:** Which root folder holds the file?
- **Modification Time:** Is one file older/newer?
- **Directory Semantics:** Does the folder name imply a 'Final' or 'Archive' status?
- **Filename Quality:** Does one have a descriptive name while the other is `IMG_1234`?
- **Source:** Was it dumped from a flash drive vs organized by a human?
