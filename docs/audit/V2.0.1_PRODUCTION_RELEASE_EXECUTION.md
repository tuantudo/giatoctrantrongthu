## 6. THẨM ĐỊNH VÀ HƯỚNG DẪN CẬP NHẬT CLOUDFLARE WAF

### A. Hiện trạng Endpoint `POST /api/member/support`:
- Hiện tại, request `POST /api/member/support` nhận phản hồi **`HTTP 403 Forbidden`** từ Cloudflare Edge WAF (`VERIFIED`).
- Do môi trường thực thi không chứa `CF_API_TOKEN` để gọi API Cloudflare tự động, thao tác cập nhật cần được Tuấn áp dụng trực tiếp trên Cloudflare Dashboard.

### B. Biểu thức Wirefilter chuẩn xác cần cập nhật:
- **Tên Rule:** `Emergency Block API Mutations`
- **Hành động (Action):** `Block`
- **Biểu thức Wirefilter thay thế:**
```text
(http.request.method in {"POST" "PUT" "PATCH" "DELETE"} and http.request.uri.path starts_with "/api/" and not (http.request.method eq "POST" and http.request.uri.path in {"/api/member/login" "/api/member/proposals" "/api/member/change-password" "/api/member/support"}))
```
- **Cam kết an ninh:** Biểu thức trên chỉ miễn trừ duy nhất phương thức `POST` cho 4 endpoints thành viên, tiếp tục khóa cứng 100% các method `PUT`, `PATCH`, `DELETE` và toàn bộ các API quản trị `/api/admin/*`.
