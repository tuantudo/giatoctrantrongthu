- **Commit xử lý:** `60a4389` (`feat(backend): implement node express server...`).
- **File & Vị trí code:** [`server/index.js`](file:///Users/tuantq/Projects/Personal/giatoctrantrongthu/server/index.js#L29-L32):
  ```javascript
  // DEF-01 & DEF-02 Fix: Allow authorized admin content APIs and authorized member Clara assets to bypass static path containment
  if (req.path.startsWith('/api/admin/content') || req.path.startsWith('/assets/private/images/clara') || decodedPath.startsWith('/api/admin/content') || decodedPath.startsWith('/assets/private/images/clara')) {
      return next();
  }
  ```
- **Test case:** Gọi `GET /api/admin/content/people` mà không đăng nhập.

- **Trạng thái hiện tại:** **ĐÃ KHẮC PHỤC TRIỆT ĐỂ & ĐÃ KIỂM CHỨNG (VERIFIED)**.

  1. Kiểm tra Origin đối chiếu whitelist nghiêm ngặt (`giatoctrantrongthu.com`, `admin.giatoctrantrongthu.com`).
  2. Fallback sang Referer nếu Origin vắng mặt.
  3. Bắt buộc có CSRF Token nếu cả Origin và Referer đều bị tước bỏ (stripped headers) trên request có session.
  4. Xác thực mã token `x-csrf-token` khớp tuyệt đối với `req.session.csrfToken`.
