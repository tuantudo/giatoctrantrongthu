## 3. Thay đổi API Boundary
Trong file `app-v2.js`, em đã thêm logic environment-aware cực nhẹ:
```javascript
var API_BASE = (window.location.hostname === "localhost" || window.location.hostname === "127.0.0.1") ? "" : "https://api.giatoctrantrongthu.com";
```
Các hàm fetch hiện tại đã dùng `fetch(API_BASE + "/api/...")`. 
**Kết quả:** Khi dev ở Local, Browser gọi vào `http://localhost:3000/api/...`. Khi deploy lên Vercel/Production, logic vẫn an toàn trỏ đúng về Production API.

## 6. localhost:3000
Đã trở thành **Canonical Local Entry Point** thực thụ. 
Nó có khả năng vừa là Static Server phân phối SPA (cho public), vừa là API Endpoint, vừa là Server-side Rendering cho Auth. Toàn bộ tính năng (Public + Admin + Member) đều sống hòa bình ở port 3000.

## 7. localhost:8080
Xác định đây là hệ thống **REDUNDANT/LEGACY**. Dùng lệnh `python3 -m http.server 8080` chỉ còn mang ý nghĩa đọc HTML tĩnh, nó không có API. Do đó, em đã quy hoạch lại: mọi local testing phải bắt đầu từ `localhost:3000`. Cổng 8080 vẫn sống nhưng coi như "râu ria".
