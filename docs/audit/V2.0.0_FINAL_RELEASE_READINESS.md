## 6. KIỂM CHỨNG CƠ CHẾ BẢO VỆ PRODUCTION API / DB TỪ PREVIEW

> [!IMPORTANT]
> **Đính chính Nguyên lý Kỹ thuật theo Chỉ thị của Tuấn:**  
> CORS là cơ chế do **trình duyệt (browser-side)** cưỡng chế đối với các yêu cầu chéo nguồn AJAX/Fetch; **CORS không phải là rào chắn phía máy chủ (server-side security)** để ngăn chặn các request can thiệp trực tiếp hoặc các client giả mạo header.  
> Do đó, tính cô lập giữa Preview và Production DB được thẩm định dựa trên **các rào cản máy chủ thực tế đã được kiểm thử (TESTED & PROVEN)**.

### Bằng chứng thực nghiệm qua kiểm thử mạng trực tiếp:

1. **Rào cản Cloudflare Edge WAF (Thử nghiệm thực tế với `POST /api/admin/users` qua Preview):**
   - **Thao tác:** Gửi lệnh mutation HTTP `POST` tới endpoint quản trị qua tên miền Vercel Preview:
     ```bash
     curl -X POST -H "Content-Type: application/json" \
       -d '{"username":"hacker"}' \
       https://giatoctrantrongthu-git-release-v200-tuantqs-projects-74ccf90b.vercel.app/api/admin/users
     ```
   - **Kết quả thực tế:** **`HTTP/2 403 Forbidden`** từ Cloudflare Edge (`Ray ID: a58c2d042e36dd9c`) $\rightarrow$ **`PROVEN`**.
   - **Cơ chế:** Quy tắc WAF `Emergency Block API Mutations` chặn cứng toàn bộ các HTTP method biến đổi trạng thái (`POST`, `PUT`, `PATCH`, `DELETE`) trước khi chạm tới server NAS.
2. **Rào cản Xác thực Phiên Server-side (Thử nghiệm thực tế với `POST /api/member/proposals` qua Preview):**
   - **Thao tác:** Gửi lệnh gửi đề xuất tới endpoint được WAF miễn trừ qua tên miền Vercel Preview mà không có cookie đăng nhập:
     ```bash
     curl -X POST -H "Content-Type: application/json" \
       -d '{"person_id":"@I1@","field":"notes","suggested_value":"test"}' \
       https://giatoctrantrongthu-git-release-v200-tuantqs-projects-74ccf90b.vercel.app/api/member/proposals
     ```
   - **Kết quả thực tế:** **`HTTP/2 401 Unauthorized: {"ok":false,"error":"Chưa đăng nhập"}`** từ Node.js Express (`Ray ID: a58c2cc6ab92dd9c`) $\rightarrow$ **`PROVEN`**.
   - **Cơ chế:** Express kiểm tra `req.session.accountId` trực tiếp từ bộ nhớ phiên. Vì khách truy cập Preview không có phiên đăng nhập hợp lệ, yêu cầu bị từ chối ngay lập tức, **hoàn toàn không có dữ liệu nào được ghi vào CSDL Production**.
